5. Script starts a download 6 seconds after your click

What this simulates: a script that waits, then starts a download by itself. The file is NOT the result of the link you clicked; a script creates a hidden link and clicks it later. Nothing you did in the last 4 seconds explains the download.
Expected: a dialog asks you ("started by itself"); choose Block or Allow.
This is NOT a slow network. If a real link you clicked is slow to start downloading, it is still allowed: the extension remembers that your click started a navigation to that exact file. Test that in 5b.
