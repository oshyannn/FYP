Download guard test site

Everything here is harmless: the 'program' files are plain text with a program-like name. Rules being tested:

  • You click + the file is from the same website = allowed
  • Nothing clicked (page or script starts it) = a dialog asks you (Block / Allow once / Always allow this site), even on trusted sites. The file is held (not saved) until you answer; no answer in 60 s = Block
  • You click, but the file is from another website = a dialog asks you
  1. 1. You click a download link — expect: downloads, no warning
  2. 2. Page sends you an .exe by itself (meta refresh) — expect: dialog
  3. 3. Hidden iframe loads an .exe — expect: dialog
  4. 4. Script clicks a hidden link on load — expect: dialog
  5. 5. Script starts a download 6 s after your click — expect: dialog
  6. 5b. Slow network: real link, server answers after 6 s — expect: allowed
  7. 6. You click, but the file comes from a different website — expect: dialog
  8. 7. Injected script starts the download the moment you click — expect: NOT blocked (known limit)
  9. 8. Normal files (.pdf .png .txt) — expect: no warning

Known limit (test 7): the extension cannot tell a real download button from a malicious script attached to a button you click. It only sees: a person clicked, same website.

A site that is confirmed malicious (on a blacklist / flagged by the backend) is still blocked outright with a notification, no dialog.

Tip: after "Always allow this site" a site is allowed for 30 days; remove and re-add the extension to reset it.
