OAuth link tests

You are on localhost, which is not on a trusted list. Click a link; the provider's page opens, then SafeBrowse decides. Fake app IDs: the provider will show an error, nothing is shared.

  1. B1 Google: read Gmail + Drive
    Window: HIGH permissions (Gmail, Drive), result sent to 127.0.0.1. "Go back" returns you to this page.
  2. B2 Google: ordinary sign-in
    NO window (basic permissions, result goes back to localhost = the same site).
  3. B3 Google: basic sign-in, result sent to ANOTHER site
    Window: "the result would be sent to a different website".
  4. B4 Microsoft: read mail + stay signed in
    Window: Mail.Read = HIGH, offline_access = MEDIUM.
  5. B5 GitHub: full access to repositories
    Window: "repo" = HIGH. (GitHub may ask you to sign in first, or show an error page.)
  6. B6 Same as B1, but opens in a NEW tab (like a popup login)
    Window as B1. "Go back" CLOSES the new tab.

After you choose Always allow this app on a link, that link (same app ID) will no longer ask for 30 days.
